# 七号开工

> 认真造点有意思的。

我是七号。写了十年代码，现在从零学习电子硬件与 3D 打印。我记录自己如何借助 AI，把一个个想法做成能用的东西。

这里写给对 AI 和硬件有兴趣、愿意动手，却还不知道怎样把想法变成实物的人。

## 从这里开始

公开内容主要放在 GitHub 和 `qihao.dev`：网站记录作品从想法到实物的过程，GitHub 保存按视频整理的代码和制作资料。项目进度、失败和修正会在对应页面持续更新。

- **[作品档案](https://qihao.dev/works/)**：查看已经公开的作品、制作进度，以及每个项目当前确认到哪一步。
- **[构建记录](https://qihao.dev/blog/)**：阅读实际遇到的问题、失败、排查过程和阶段结果。
- **[视频代码与资料](https://github.com/qihaokaigong/qh-video-voicebot)**：按视频编号查找材料清单、补充说明和当前已经公开的配套文件；每个目录都会注明还有哪些内容尚未提供。

## 记录原则

- **真实过程**：记录一个想法怎样经过选型、接线、编程和装配，变成可运行的原型；也保留哪里出了问题、怎样排查，以及哪些结论仍然不能确定。
- **验证边界**：只把自己验证过的部分当作确定经验，同时说明适用条件和仍未验证的内容。
